## Technical Implementation

### Scripts Created

1. **unified_fiche_importer.py** - Main import script for HTML fiches
   - Handles Reference, Skills, and Resumes
   - Auto-detects disciplines
   - Converts HTML to Markdown
   - Prevents duplicates

2. **import_resume_images.py** - Resume image importer
   - Links images to multiple matching fiches
   - Smart keyword matching
   - Auto-extracts image order and descriptions

3. **import_rms_fiches.py** - RMS fiche importer (previous)
4. **import_rms_images.py** - RMS image importer (previous)
5. **import_images_to_db.py** - AMBOSS case images (previous)
6. **import_fiche_images_to_db.py** - SSP fiche images (previous)

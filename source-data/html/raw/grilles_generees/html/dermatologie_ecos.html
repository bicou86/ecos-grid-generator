1. Dermatoses Inflammatoires

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Psoriasis vulgaire Lésions cutanées, prurit parfois, problèmes unguéaux, cuir chevelu, douleurs articulaires, généralement chronique, soleil améliore, antécédents familiaux. Facteurs déclenchants : traumatisme ! Médicaments (β-bloquants, lithium, IEC), stress, alcool, tabac, infections, maladies associées (hypertension, diabète, Crohn, tumeurs), antécédents familiaux Peau : plaques érythémato-squameuses, hyperkératoses gris-argenté nettement délimitées aux sites de prédilection (faces d'extension, genoux, coudes + zones de frottement > sillon interfessier), symétriques, généralement bien délimitées, érythrodermie éventuelle. Phénomène de la bougie (desquamation), phénomène de la dernière pellicule (membrane basale se détache, peau fragile), phénomène de la rosée sanglante (saignements punctiformes). Ongles : onycholyse distale, taches d'huile (jaunâtres), ongles en dé à coudre. Cheveux : lisière d'implantation + rétro-auriculaire. Articulations : arthrite psoriasique (radiologiquement similaire PR, mais atteint carpe, IPD, dactylite). Langue : glossite exfoliatrice marginée Biopsie éventuelle, frottis éventuel. Muqueuses non atteintes ! Description : aux faces d'extension multiples lésions nettement délimitées partiellement surélevées érythémato-squameuses en plaques Psoriasis léger : corticoïdes topiques (III/IV), vitamine D, vaseline salicylée*, bains*, goudron + photothérapie éventuels. Psoriasis modéré : PUVA, UVB, rétinoïdes. Psoriasis sévère : immunosuppresseurs (méthotrexate, ciclosporine), biothérapies. Psychothérapie éventuelle ! Associations de patients *pour kératolyse (éliminer squames dures). Corticoïdes systémiques contre-indiqués car rebond ! Vitamine D : inhibe cytokines. Biothérapies : anti-TNF-α. Immunosuppresseurs : méthotrexate, ciclosporine A. Agrégation familiale parfois. P. pustuleuse : pustules stériles. P. inversa : plis, aisselles, ombilic, anogénital. P. vulgaire : psoriasis classique. Selon taille lésions : guttata (lésions isolées), nummulaire (lésions plus grandes), géographique (étendues)
Ulcère de jambe Ulcère (souvent membres inférieurs), décubitus, âge. Ulcère artériel : plaie après traumatisme/effort qui ne guérit pas, tabac, dyslipidémie, diabète, claudication/AOMI éventuelle, surélévation douloureuse. Ulcère veineux : insuffisance veineuse chronique, varices, thrombose veineuse profonde, œdèmes, surélévation soulage. Ulcère diabétique : diabète, polyneuropathie éventuelle, zones de pression, souvent pied. Décubitus : alitement veineux/artériel/diabétique Autres : décubital, vasculite, lymphœdème, infectieux, tumoral, pyoderma gangrenosum. Rechercher signes IVC : malléolaire-médial, œdème, corona phlebectatica, eczéma de stase (exsudation, prurit), lipodermosclérose. Rechercher signes ulcère artériel : tibial-latéral, souvent après traumatisme/effort, cyanose bord ulcère, surélévation douloureuse ! Rechercher signes ulcère diabétique : zones de pression (têtes métatarsiennes souvent). Examen neurologique (sensibilité, motricité, réflexes, vibration, position), examen vasculaire : pouls pédieux, recoloration, chaleur, auscultation, ganglions lymphatiques 1. Frottis (exclusion infection), biopsie (si ulcère >2-3 semaines) 2. Mesure artérielle/IPS + échographie éventuelle + angiographie (problème artériel/diabétique), écho-Doppler veineux (problème veineux) 3. Radiographie/IRM éventuelles (atteinte osseuse) 4. Interdisciplinaire : angiologie, chirurgie vasculaire, dermatologie, médecine interne/diabétologie Thérapie complémentaire : tous - Antibiotiques si infection - Chirurgie si ostéomyélite - Pansement sous vide éventuel - Couverture plaie greffe peau, lambeau ou cloques autologues éventuels. Ulcère veineux 1. Curettage, pommade (pâte de zinc), bandage compression 2. Traitement cause : IVC - Bas compression*(avec soins cutanés + protection), surélévation, mouvement, médicaments, chirurgie varices éventuelle, facteurs de risque. Ulcère artériel 1. Curettage, pommade, pansement 2. Traiter facteurs de risque (diabète, hypertension) 3. Médicaments (vasodilatateurs : prostacyclines IV) 4. Si sténose vasculaire : angioplastie ou pontage 5. Dès circulation correcte : compression. Ulcère diabétique 1. Curettage, pommade, pansement 2. Antibiotiques si infection 3. Rétablir circulation artérielle : angioplastie, pontage 4. Chirurgie si ostéomyélite 5. Décharge/chaussures spéciales 6. Équilibrer diabète *seulement quand ulcère cicatrisé, avant bandage compression (envelopper avec pommade). *Commencer souvent par pustules. Décrire : fond, bord + pourtour ulcère. Type : U. veineux, artériel, artério-veineux, autre. Ulcère diabétique est sous-forme ulcère artériel, cause : trouble circulation et/ou perte sensibilité. Complications : infection, ostéomyélite, eczéma, absence cicatrisation, amputation

2. Acné et Rosacée

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Acné Lésions cutanées visage, début puberté, psychisme (conséquence acné), antécédents familiaux (souvent positifs) Comédons (points noirs comme lésion primaire, ouverts ou fermés), puis pustules + papules + nodules, puis excoriations, cicatrices. Formes : A. comédonienne (nombreux comédons ouverts ou fermés), papulo-pustuleuse (beaucoup inflammation + pus), conglobata (beaucoup inflammation + kystes), A. excoriée (jeunes femmes peau impure excoriations sans comédons ni nodules), Acné fulminans (sur fond A. conglobata ; fièvre, leucocytose, myalgies et arthralgies), Hidradénite suppurée (cicatrisation glandes apocrines), médicamenteuse Acné légère : rétinoïdes topiques. Acné modérée : rétinoïdes topiques + antibiotiques (topiques ou systémiques), femmes contraception éventuelle. Acné sévère : rétinoïdes systémiques/isotrétinoïne (seule thérapie, Roaccutan) ou antibiotiques ou anti-androgènes Sans comédons > pas d'acné ! Diagnostic différentiel dermatoses acnéiformes (médicaments, huile/goudron, chlore, cosmétiques, soleil/Majorque). Avant traitement topique : laver peau !
Hidradénite suppurée/Acné inversa Chronique, nodules, cicatrices dans régions glandes apocrines (aisselles, inguinal, péri-anal, fessier, sous-mammaire), femmes souvent. Facteurs de risque : tabac, obésité Lésions nodulo-kystiques acnéiformes, cicatrices, pas de comédons fermés Seule thérapie curative : chirurgie. Sinon : antibiotiques, corticoïdes systémiques, isotrétinoïne, anti-TNF-α Définition : trouble kératinisation gaine radiculaire externe follicule terminal avec inflammation. Parfois patients ont acné classique, folliculite additionnelles
Rosacée Lésions cutanées visage, modification nez, atteinte oculaire parfois. Facteurs de risque : soleil, alcool, café, stress, alimentation épicée, changements température Peau : érythème (d'abord flush, puis persistant), papules (parfois nodules), pustules, télangiectasies (nez + joues), rhinophyma. Yeux : aussi atteints ? 1. Topique : antibiotiques 2. Systémique : antibiotiques, isotrétinoïne 3. Chirurgie (rhinophyma) 4. Laser/coagulation (télangiectasies) Cause multifactorielle. Diagnostic différentiel : LED, lupus pernio/sarcoïdose, maladie de Wegener, eczéma, flush carcinoïde, érythème héliotrope dermatomyosite. Pas de comédons !!!!

3. Eczémas

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Eczéma atopique/Dermatite atopique = Neurodermatite Aigu ou chronique, localisation, aspect, profession/loisirs/déclencheurs/animaux, allergies, prurit, antécédents familiaux, autres atopies (asthme/rhinite/conjonctivite, allergies alimentaires), début souvent enfance (début généralement croûtes de lait). Allergènes : pollens, acariens, arachides, protéines lait Aigu : érythème, vésicules, suintement, œdème, excoriations éventuelles, généralement plis accentués. Chronique : érythème, desquamation, rhagades, lichénification, croûtes éventuelles, sec, excoriations éventuelles. Enfant : souvent signe Hertoghe (raréfaction sourcils latéraux) + pli Dennie-Morgan (double pli paupière inférieure), rhagades lobes oreilles > signes atopie 1. Prick-test (type I) 2. Sérologie (IgE). Explication : eczémas souvent aux plis ! 1. Éliminer allergène 2. Corticoïdes topiques/crème, inhibiteurs calcineurine topiques 3. Protection cutanée (sec > pommade, suintant > crème, inflammation > corticoïde crème/pommade, infecté > pommade antibiotique désinfectante). Si professionnel : gants Dans 20% IgE non élevées ! > Eczéma dit non-atopique (symptômes identiques). Aspect différent chez chacun ! Souvent surinfection > croûtes jaune-miel + bulles !
Dermatite de contact - Eczéma de contact allergique - Eczéma de contact irritatif Allergique (type IV) : aigu ou chronique, déclencheurs/allergies (nickel, colorants, parfums, conservateurs), profession/loisirs/animaux, prurit, s'étend. Irritatif (non-allergique) : aigu ou chronique, déclencheurs (agents de contact : travail humide, substances toxiques, mécanique), profession, loisirs, généralement limité au site de contact Aigu : érythème, vésicules, suintement, œdème. Chronique : érythème, desquamation, rhagades, lichénification, croûtes éventuelles, sec. Explication eczéma de dessication : peau sèche/dessication, hygiène insuffisante, climat froid sec peuvent aussi faire eczéma > protection cutanée (pommade !) 1. Patch-test (diagnostic différentiel allergique/irritatif) 1. Éliminer substance déclenchante 2. Corticoïdes topiques, inhibiteurs calcineurine topiques 3. Protection cutanée (sec > pommade, suintant > crème, inflammation > corticoïde crème/pommade, infecté > pommade antibiotique désinfectante). Si professionnel : porter gants Allergique ex : personnes contact nickel, métaux, parfums, conservateurs, colorants, instruments dentaires, bijoux, cosmétiques, produits soins, désinfectants... Irritatif : travaux humides, substances toxiques, goudron, huile, mécanique, acides, bases, sels, solvants, mécanique > coiffeurs, boulangers, fleuristes, métiers santé, chimistes
Eczéma séborrhéique Desquamation peau, rougeur, pas de prurit Érythème, squames épaisses → modification cutanée érythémato-squameuse souvent lisière cheveux + sillon naso-labial, visage, dos, poitrine, souvent début pellicules (parfois grasses + rougeur pas toujours nécessaire), jaunâtres Adultes : 1. Corticoïdes topiques + inhibiteurs calcineurine 2. Crèmes + shampooings antimicrobiens 3. Acide salicylique (kératolyse) 4. Isotrétinoïne (systémique) 5. Protection cutanée (sec > pommade, suintant > crème, inflammation > corticoïde crème/pommade, infecté > pommade désinfectante). Nouveau-nés : crème oxyde zinc, corticoïdes topiques courts avec ajout antimycosique Souvent nouveau-nés (premiers 3 mois, généralement dans 1ère année guérison spontanée, souvent associé dermatite couches) ou SIDA. Chez adultes : eczéma gras-brillant desquamant

4. Pathologies Vasculaires Cutanées

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Insuffisance veineuse chronique IVC Œdèmes, coloration foncée peau, induration, ulcère éventuel. Facteurs de risque : TVP/syndrome post-thrombotique, varices, insuffisance cardiaque, diabète, obésité, tabac, hypertension, dyslipidémie, troubles circulation, station debout/assise Examiner veines debout ! Inspection (eczéma de stase, œdèmes, corona phlebectatica, hypodermite/pseudo-érysipèle, purpura de stase, hyperpigmentation, dermato-lipo-fascio-sclérose, atrophie blanche, ulcère ou cicatrisé) + palpation*. Examen vasculaire artériel (exclure problème artériel type AOMI), examen neurologique (exclure polyneuropathie, diabète) Bilan biologique (facteurs de risque), écho-Doppler veineux éventuellement avec Doppler couleur 1. Prophylaxie : pompe musculaire/mouvement, surélévation, bas compression* classe I-II suffisant, douche froide 2. Traiter facteurs de risque : perte poids, sport, arrêt tabac, traitement hypertension, réduire station debout/assise 3. Médicaments (retour veineux), daflon, aspirine, prostaglandines E 4. Chirurgie varices si varices : crossectomie, stripping, mini-phlébectomie (veines collatérales + réticulaires), sclérothérapie/laser (télangiectasies) *avant exclure problème artériel ! IVC : microangiopathie à cause trouble drainage veineux dans cadre varices ou syndrome post-thrombotique. *Stades selon Weber : Stade I : œdème, corona phlebectatica (télangiectasies péri-malléolaires + para-plantaires). Stade II : hypodermite (inflammation peau, pseudo-érysipèle), eczéma de stase (suintement, croûtes), purpura de stase + purpura jaune d'ocre (hémosidérine car extravasats érythrocytaires > brun), atrophie blanche (fibroses car ischémie), dermatolipolérose (peau indurée empâtée). Stade III : ulcère (éventuellement cicatrisé), sur fond dermatoliposclérose

5. Dermatoses Bulleuses

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Pemphigoïde bulleuse Formation bulles douloureuses intenses, érosions éventuelles, atteinte muqueuse. BP : prurit chez âgés. PV : lésions muqueuses buccales chroniques. Grossesse + bulles : pemphigoïde gestationis ! Stade bulleux : vésicules, bulles, érosions, souvent étendues + signe de Nikolsky (positif généralement seulement pemphigus vulgaire). Stade non-bulleux (diagnostic difficile) : lésions eczémateuses + urticariennes, nodules de prurigo... très variable. Examiner muqueuses (génito-ano-buccales) ! > P. vulgaire commence souvent muqueuse buccale (érosions chroniques) 1. Frottis + biopsie + immunofluorescence (voit lieu clivage + dépôts anticorps (IgG et C3 chez pemphigoïde))* Pemphigoïde : visage épargné, >70 ans. Pemphigus vulgaire : début visage/bouche, 40-70 ans 1. Corticoïdes topiques 2. Corticoïdes systémiques (prednisolone) 3. Immunosuppresseurs (méthotrexate, tétracyclines) 4. Immunoglobulines IV éventuelles (d'abord cortisone, puis immunosuppresseurs épargneurs de cortisone) Sous-épidermique : pemphigoïde, P. gestationis, aussi comme paranéoplasie obligatoire (autres anticorps) ; anticorps contre BP 180/230. Intra-épidermique : pemphigus vulgaire ; anticorps contre desmogleines 1+3. Pemphigoïde plus fréquemment associée maladies système nerveux central (SEP, démence, Parkinson)
Dermatite herpétiforme Formation bulles prurigineuses ou brûlantes (non douloureuses), maladie cœliaque Papulo-vésicules groupées + excoriations, symétriques faces extension extrémités + fesses 1. Frottis, biopsie cutanée + immunofluorescence (Ig-A) 2. Sérologie (IgG + IgA contre transglutaminase tissulaire, anticorps gliadine) 3. Biopsie intestin grêle (maladie cœliaque) 1. Régime sans gluten (rémission) 2. Dapsone Dermatose bulleuse auto-immune (comme P. vulgaire + pemphigoïde) souvent associée maladie cœliaque + autres pathologies auto-immunes ! Anticorps contre transglutaminase

6. Infections Cutanées

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Zona Vésicules douloureuses, fièvre éventuelle, état général altéré. Demander si varicelle contractée. Facteurs déclenchants : traumatisme, immunosuppression, VIH Peau : vésicules groupées sur fond érythémateux, croûtes (suivent vésicules), selon dermatome (chez immunodéprimés atteinte multi-segmentaire), parfois en ceinture. Examen neurologique : sensibilité (dermatome) + nerfs crâniens. Examiner œil + oreille : si atteints consultation ophtalmologique si œil atteint 1. Frottis (fond vésicule) 2. Sérologie (anticorps) 1. Thérapie antivirale valaciclovir* 2. Analgésie (AINS) 3. Teinture zinc locale (cicatrisation) *chez âgés même 5-7 jours après début symptômes pour réduire risque névralgie post-zostérienne Varicelle : exanthème prurigineux avec vésicules, pustules, érosions, croûtes, ciel étoilé, polymorphe
Herpès labial/in loco (ailleurs) Boutons de fièvre, prodromes (tension, douleur, picotements), récidive, douleur. Facteurs déclenchants : soleil, stress, immunité faible, fièvre Vésicules groupées sur fond érythémateux, érosions + croûtes éventuelles, douloureux 1. Frottis éventuel (fond vésicule) 2. Sérologie (anticorps) 1. Désinfection + cicatrisation (pommade zinc) 2. Aciclovir, valtrex (si symptômes durent plus 3 jours). Prophylaxie : si 8-10 par an > valtrex faible dose

7. Photodermatoses

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Lucite polymorphe/Allergie solaire Lésions polymorphes heures à 1-2 jours après exposition solaire : chez chaque personne différent, généralement amélioration au cours été Lésions polymorphes, mais chez chaque patient toujours identiques ! Tests de photosensibilité, photoprovocation, photopatch-test 1. Protection solaire importante (surtout UVA) 2. Accoutumance progressive 3. Corticoïdes locaux, antihistaminiques éventuels Généralement chronique-récidivante
Dermatite phototoxique/photoallergique Érythème aigu zones exposées soleil. Facteurs déclenchants : médicaments généralement, plantes/herbes, parfums Phototoxique : ne diffuse pas, seulement zones exposées, pigmentation post-lésionnelle. Photoallergique : diffuse, épargne menton + rétro-auriculaire, latence légère Tests de photosensibilité, photoprovocation, photopatch-test 1. Éliminer facteur déclenchant 2. Antihistaminiques si photoallergique 3. Compresses rafraîchissantes Photoallergique : soleil transforme substance/déclencheur en haptène > réaction allergique. Phototoxique : substance est phototoxique > rend peau photosensible > soleil agit alors nocif > érythème

8. Troubles Capillaires

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Effluvium télogène Chute cheveux diffuse, carences (fer), métabolique (hypo- + hyperthyroïdie, prolactinome), post-partum, stress (infections, fièvre, chirurgie, anesthésie), maladies systémiques, médicaments, chronique-idiopathique Chute cheveux diffuse (reconnaissable généralement seulement quand 25-50% tombés) Anamnèse capillaire générale : fragilité, amincissement, longueur insuffisante, croissance excessive, en aires ou diffuse, médicaments, stress, psychisme, hormones. Bilan biologique (carences), frottis (si ulcères > exclusion infection), biopsie (si suspicion alopécie cicatricielle : LED), test traction, trichogramme (stade racine) 1. Si cause connue corriger 2. Préparations L-cystéine + biotine 3. Levure médicinale (incertain) Cheveux passent trop rapidement phase télogène. Diagnostic différentiel : forme diffuse alopécie aréata. Diagnostic différentiel : alopécie androgénétique (effluvium lent, hommes début frontal, femmes raie)
Alopécie aréata/Pelade Chute cheveux circonscrite ou forme diffuse possible, tout tête/corps ou seulement régional, antécédents familiaux positifs Aires alopéciques rondes-ovales non-cicatricielles, épilabilité augmentée (test traction positif > peut arracher touffes), aussi cils/sourcils/barbe/cheveux corps possibles, toute tête/corps peut être atteint ! Ongles en dé à coudre notamment, repousse cheveux blancs (typique) Biopsie 1. Rémission spontanée (50%) attendre 2. Corticoïdes topiques 3. Immunothérapie topique avec allergènes (stimule pousse) 4. Corticoïdes systémiques Auto-immun, agrégation familiale, tout âge possible, hommes = femmes, souvent récidives. Si cicatriciel : lupus discoïde, cas graves teigne du cuir chevelu

9. Tumeurs Cutanées

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Mélanome malin Lésion préexistante, modification (taille, couleur), soleil, antécédents familiaux, symptômes B. Facteurs de risque : nombreux naevi, phototype clair, antécédents familiaux, gros naevi congénitaux, soleil, solarium Peau : règle ABCDE (Asymétrie, Bords, Couleur, Diamètre, Évolution/modification), inspecter toute peau (cuir chevelu, ongles, plante pieds, tout), déterminer phototype. Muqueuses : bouche, organes génitaux Dermatoscopie (loupe), biopsie (exérèse ou biopsie si gros), préopératoire : stadification par scanner (métastases) + détermination ganglion sentinelle 1. Chirurgie sauf si métastases 2. Contrôles. 1. Mélanome in situ/mélanome invasif sans métastases/lentigo maligna : exérèse chirurgicale, si ganglion sentinelle positif > lymphadénectomie régionale totale 2. Mélanome métastatique : palliatif éventuel. Exérèse, chimiothérapie-radiothérapie éventuelles Lentigo maligna (peut devenir mélanome, UV/soleil excessifs, visage/bras/cou, hyperpigmentation brune irrégulière avec bord irrégulier). Localisation : partout peau + muqueuses ! Attention pas toujours pigmenté !
Précancroses Lésion préexistante, modification (taille, couleur), soleil, thérapie photodynamique, profession, tabac, alcool, antécédents familiaux, symptômes B Risque progression carcinome épidermoïde ou L. maligna > mélanome Kératose actinique : kératose solaire/sénile, peau exposée soleil chez adulte, phototype clair, hyperkératose rougeâtre-brune irrégulière adhérente sur plaque rougeâtre, souvent multiples, visage/tête/mains/bras. Chéilite actinique : kératose actinique aux lèvres. Lentigo maligna : carcinome in situ (précurseur mélanome), peau exposée (visage, mains, cou), aires brunes (couleurs diverses) plates nettement délimitées irrégulières cartographiques, >50 ans. Maladie de Bowen : carcinome in situ (intra-épidermique, précurseur carcinome épidermoïde), plaque rouge desquamante croûteuse nettement délimitée, résistante traitement, toute partie corps possible (aussi génital), surtout zones soleil, >50 ans généralement. Érythroplasie de Queyrat : analogue maladie Bowen mais génital/buccal, cause VPH, précurseur carcinome épidermoïde, foyer rouge foncé mou, facilement vulnérable, progression rapide. Leucoplasie : épaississement blanchâtre adhérent muqueuse (buccale, génitale), facteurs de risque irritations chroniques (tabac, alcool, prothèse...) Règle ABCDE (Asymétrie, Bords, Couleur, Diamètre, Évolution/modification), inspecter toute peau (cuir chevelu, ongles, plante pieds, tout), déterminer phototype. Ganglions lymphatiques ! Muqueuses. Dermatoscopie, biopsie éventuelle KA : cryothérapie ; curettage, Efudix (médicament cytotoxique), imiquimod (Aldara), photothérapie. L. maligna : exérèse. M. Bowen : cryothérapie, Efudix, photothérapie, exérèse. Érythroplasie Q : exérèse, laser. Leucoplasie : éliminer irritation (souvent amélioration), sinon exérèse

10. Autres Pathologies

Pathologie Anamnèse/Symptômes Examen Physique Procédures/Examens Thérapie Commentaires/Faits
Urticaire U. spontanée : durée (aiguë, chronique), lésions cutanées, prurit, voyages, profession, loisirs, stress, angio-œdèmes. Facteurs déclenchants : médicaments, infections, allergies dont alimentaires, venin insectes. U. physique : facticia/pression, froid, chaleur, lumière. Autres U. : cholinergique, contact, syndrome allergique oral U. spontanée : urticaires multiples (avec œdème central + liseré érythémateux, pas desquamation, fugaces, pas excoriations), dermographisme urticarien éventuel. U. facticia : grattage, frottement déclenche urticaires > dermographisme urticarien. U. physique : urticaires. Explication : syndrome allergique oral = forme spéciale urticaire de contact (prurit avec allergènes croisés) U. aiguë : pas biopsie sauf si urticaires >24h, pas diagnostic (sauf si suspicion origine allergique > exploration allergologique) > attendre, guérit dans 90% spontanément. U. chronique : biopsie, bilan sanguin, VS + CRP, selon anamnèse/examen. U. physique : provocation pour diagnostic Tous types U. : antihistaminiques ! (jusqu'à 4 fois dose). U. aiguë : corticoïdes systémiques additionnels si réaction forte (anaphylaxie, œdème laryngé). U. chronique : antihistaminiques (1-3 mois), si pas amélioration : anti-leucotriènes, immunosuppresseurs, omalizumab* Classification : U. spontanée : aiguë <6 semaines, sinon chronique. U. cholinergique : U. par élévation température corporelle. U. de contact : par contact substances allergiques ou non-allergiques. *Anticorps anti-IgE
Prurit/Démangeaisons Dimensions bien demander : qualité (brûlure, picotements, fourmillements), facteurs aggravants/améliorants, EVA, début/durée, comportement grattage. Facteurs déclenchants : dermatose, allergie, médicaments, maladie interniste, psychiatrique/stress, neurogène, grossesse Peau : inspection + palpation, lésions cutanées ? Examen interniste. Examen psychique si suspicion *Couper ongles, graisser peau (ou crème), éviter stress, relaxation, éviter fibres synthétiques, refroidir. Exploration allergologique, modifier médicaments éventuellement. Rechercher cause interniste* : bilan sanguin + sérologie (parasites), imagerie (radiographie thorax, scanner abdomen).

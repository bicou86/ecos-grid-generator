Générateur de grilles d'évaluation ECOS

📋 Instructions d'utilisation

  1. Collez vos données JSON dans la zone de texte ci-dessous ou chargez un fichier JSON
  2. Cliquez sur "Générer la grille ECOS" pour créer le fichier HTML
  3. Prévisualisez le résultat
  4. Téléchargez le fichier HTML généré

Format attendu : Les données doivent contenir les sections anamnese, examen et management. La section communication est standardisée et sera ajoutée automatiquement.

Note : La section Communication est identique pour tous les cas ECOS (4 critères, notation A-E, 25% de la note finale).

Images : Les annexes peuvent contenir des images. Utilisez le chemin "grilles_generees/images/nom-image.jpg" dans le JSON. Les images seront automatiquement converties en chemins relatifs dans le HTML généré.
